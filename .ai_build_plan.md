# Pdfeditor - AI Build Blueprint

This repository contains a lightweight, client-side PDF editing application built with Vanilla JavaScript and HTML5. It features PWA support for offline use.

## Goal
To provide a fast, privacy-focused, and accessible PDF editing tool that runs entirely in the browser without the need for server-side processing.

## Tech Stack
- **Frontend:** Vanilla HTML5, CSS3, JavaScript.
- **PWA:** Service Worker (\service-worker.js\), Web App Manifest (\manifest.json\).
- **PDF Logic:** Likely using PDF.js or a similar lightweight client-side library.
- **Styling:** Custom CSS.

## AI Guidelines
1. Maintain the "Privacy-First" approach; ensure all PDF processing remains client-side.
2. When modifying the UI, prioritize speed and responsiveness, especially for mobile users.
3. Follow the \.ai_build_plan.md\ for architectural context.
4. Ensure the PWA features (offline support, installability) are preserved during updates.
5. All code should be well-commented and follow modern ES6+ standards.
